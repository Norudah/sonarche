# The first release

Sonarche downloads, identifies and files. A library of your own, on your disk, readable by any player.

## The essentials

- Downloads keep the original stream: no re-encoding, no added loss.
- Every album goes through MusicBrainz, blanks filled and nothing overwritten without reason.
- An existing music folder can be imported, and the app says what it did with it.
- Windows ships alongside macOS.

## Settings

Light or night theme, language, a movable library folder, API keys you can test before relying on them, and adjustable politeness delays towards the services being asked.
